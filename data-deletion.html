Data Deletion Instructions

Facebook Page Uploader is a Windows desktop application. The application is designed to keep operational records on the computer where it is installed.

1. Revoke Facebook access

  1. Open your Facebook account settings.
  2. Find the section for Business Integrations or Apps and Websites, depending on the settings interface shown to you.
  3. Locate Facebook Page Uploader, if it appears, and choose Remove.
  4. Confirm the removal. This revokes the app's future access through that authorization.

2. Remove locally stored application data

  1. Close Facebook Page Uploader.
  2. Use the application's account or Page disconnection feature to remove saved Page credentials when that feature is available.
  3. Uninstall the application if you no longer need it.
  4. To remove remaining local records, delete the application's data folder after closing the application. The exact folder location will be documented in the release version.

3. Request assistance

For help with a data deletion request, email didikforanno@gmail.com. Include the app name and a description of your request. Do not send your Facebook password, App Secret, or access token.

4. Data handled by Meta

Revoking the application's access does not delete content already published to a Facebook Page. Manage or delete published Page content directly through Facebook Page tools.
